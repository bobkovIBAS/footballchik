# Football Simulator · FootballIntegration

- Рабочая игра — приватный Football Simulator в Team Create, UniverseId `10776358844`, PlaceId `93666872365168`. `fotball-integrated.rbxl` в этой папке — контрольная копия. Для автономных проверок используй её, для постоянных правок — облачный Place. См. [порядок Team Create](docs/TEAM_CREATE.md).
- Общие знания хранятся в `game.ServerStorage.DeveloperDocs` облачного Place. Перед задачей прочитай `StartHere` через Studio MCP. Существенные изменения механик записывай в общие документы в рамках той же задачи, без отдельной просьбы. См. [правило ведения знаний](.codex/project/rules/project-knowledge.md).
- Перед правкой сверь полный путь локального файла либо UniverseId и PlaceId согласованной цели, экземпляр Studio MCP и режим Edit. Используй открытое окно нужного проекта. Дополнительное окно или новый Place допустимы только при необходимости; создание новой облачной цели, публикация и изменение доступа требуют разрешения пользователя.
- Прочитай связанные скрипты и объекты. Меняй только относящиеся к задаче файлы; избегай массового рефакторинга. Экономику и DataStore меняй только по отдельному заданию. При существенной неоднозначности уточни цель, требование или область изменений.
- `src/` — локальное зеркало Luau; манифесты Rojo описывают дерево скриптов. Автоматическая синхронизация с Place не настроена. Перед изменением сверь фактический `Source`, сохрани работу соавторов и обнови затронутое зеркало вручную. Перед изменением Place зафиксируй резервную версию.
- Вноси постоянные правки в Edit и после изменения игры проверяй результат в свежем Play Mode с одним персонажем и смотри Output. Мультиплеер запускай только по явному запросу пользователя. Укажи, какую копию и какой сценарий проверил. Для изменений только документации проверь ссылки и факты.
