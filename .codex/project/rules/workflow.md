# Работа с исходниками и Studio

- Для постоянных правок используй приватный Football Simulator, UniverseId `10776358844`, PlaceId `93666872365168`. Для автономной проверки открывай локальную контрольную копию [fotball-integrated.rbxl](../../../fotball-integrated.rbxl). См. [Team Create](../../../docs/TEAM_CREATE.md).
- Переиспользуй открытое окно проекта. Сначала вызови `list_roblox_studios` и сверь путь локального файла или ID облачного Place, затем режим. По умолчанию запускай Play с одним клиентом и одним персонажем. Мультиплеер, включая `Server & Clients` и `Team Test`, запускай только по явному запросу пользователя. Заверши запущенные тобой тесты.
- Геометрия и постоянные объекты хранятся в Place. `src/` — ручное зеркало Luau. Перед правкой сверь фактический `Source` и соседние изменения; применяй правку в Edit. Затем обнови изменённые файлы зеркала. Не включай автоматическую синхронизацию и не загружай локальный снимок поверх общего Place без согласования.
- Перед изменением Place зафиксируй резервную версию. Для локального сохранения проверь путь, для общего Place используй заметку к версии. Публикация и изменение прав требуют отдельного разрешения.
- После правки игры проверь обычный сценарий в Play и Output. Для локальных тестов используй временный профиль Studio. При существенной неоднозначности спроси пользователя. Для документации проверь факты и ссылки.

Координаты, тесты и назначение сборочных инструментов — в [INTEGRATION.md](../../../INTEGRATION.md). Общий подход описан в [Roblox Standards](../../common/docs/source-of-truth.md).
