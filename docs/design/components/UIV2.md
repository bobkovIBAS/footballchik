# UIV2

Концепция задаёт два счётчика сверху, четыре цветных раздела, полосу прогресса и основное действие. На широком экране разделы находятся справа, в портрете образуют ряд, в низком ландшафте собраны в «Клуб». В зоне удара место основной кнопки занимает действие ворот. Золотая шкала показывает данные профиля, тренировочная сила берётся из `trainingPower`.

| Компонент | Назначение |
| --- | --- |
| Panel | Градиентная поверхность с контуром, нижней гранью, тенью и бликом. |
| PrimaryButton / IconButton | Игровое действие и навигация. Поддерживают фокус, наведение, нажатие и блокировку. |
| CurrencyCounter / ProgressBar | Число и шкала с анимациями подтверждённых значений. |
| StatusBadge / Notification | Комбо, готовность награды и серверные сообщения. |
| ItemCard / Modal | Подсказка первых шагов и меню разделов в компактном режиме. |

Окна клуба и игровые шкалы V2 используют существующий серверный контракт. Сессия использует один `RemoteEvent`, а клиентский загрузчик создаёт один HUD и один набор обработчиков ввода на запуск.

## Проверка в Studio

Откройте [fotball-integrated.rbxl](../../../fotball-integrated.rbxl) и запустите Play. V2 выбран в `UIV2.Config.Version` и `Workspace.FootballUIVersion`. Для сравнения с V1 используйте временную локальную копию, задайте атрибуту значение `1` в Edit и запустите новый Play. Кнопка Select на геймпаде переводит фокус к навигации V2. B закрывает окно.

Старый `fotball-uiv2-preview.rbxl` архивный. Название манифеста `uiv2-preview.project.json` сохранено для инструментов сборки.

## Иллюстрации

`assets/uiv2/HudIcons.png` содержит девять оригинальных иконок. В приватном Football Simulator `Config.AtlasImage` указывает на изображение `rbxassetid://138136561169820`, загруженное владельцем. HUD и меню «Клуб» используют отдельные ячейки этого атласа. В автономной контрольной копии с пустым `AtlasImage` Studio пытается загрузить встроенный `AtlasData` через `EditableImage`. Если эта возможность недоступна, отображаются резервные символы.

`build_atlas.py` генерирует PNG и сжатый модуль. Для регенерации нужны Pillow, zstandard и Node.js с `@resvg/resvg-js`.

## Полные экраны V2

- `ClubWindow` собирает магазин, команду, контракты, дивизионы, задания, финты и настройки. Команда показывает пять карточек выбранного дивизиона. Для переходов используются стрелки, а раздел «Прогресс» имеет три собственные вкладки.
- Покупки и контракты подтверждаются по изменению серверного снимка. При ожидании кнопки не отправляют повторную команду. Стоимости и ограничения берутся из `Balance` и `ClubRules`.
- `Rhythm` отображает окно текущего такта по серверному времени. `Goals` отображает шкалу множителей, HP и подтверждённый результат. Серверные правила и клиентский контроллер попытки удара остаются общими для V1 и V2.
- `Prompts` отображает ближайшую точку. Оба режима тренировки могут быть видны рядом как два действия одного мяча. Команды проходят через исходные `ProximityPrompt`.
- Игровые уведомления и уведомления окна используют один компонент и распределяются по текущему контексту. Серверные подтверждения имеют приоритет над коротким показом монет.
