## Как работать в Team Create

| Где | Роль |
| --- | --- |
| Облачный Place в Team Create | Рабочий источник геометрии и скриптов. Открывается через Creator Dashboard. |
| `fotball-integrated.rbxl` | Локальная контрольная копия первой объединённой сборки. Обновляйте её экспортом согласованной версии и записывайте номер облачной версии и SHA-256. |
| `src/`, Rojo, Lune | Зеркало для просмотра и сравнения Luau, локальных проверок и контролируемой сборки. Нет общего файлового репозитория и автоматической синхронизации с Team Create. |
| Codex и Studio MCP | MCP работает с открытой у конкретного разработчика Studio. До правок сверить ID, Edit и текущий `Source`. `.codex` и `AGENTS.md` не синхронизируются через Team Create; для одинаковых навыков каждому разработчику потребуется отдельно переданный набор документации и навыков. |
| Version History и `backups/` | Контрольные точки с заметкой перед крупными правками; локальные копии для восстановления, облачная история для сравнения и согласованного отката. |

Перед работой проверьте текущий общий `Source` и что редактируют коллеги. Вносите небольшие изменения в согласованном режиме Live Scripting или Drafts. При Drafts сравнивайте с общей версией перед коммитом, а через MCP уточняйте, какой `Source` читается. При необходимости переносите в `src/` только изменённые скрипты и указывайте версию, с которой сверяли. Не подключайте Rojo или Script Sync к общей игре без решения команды, какие ветки и в каком направлении синхронизируются. [Studio MCP](https://create.roblox.com/docs/studio/mcp) · [Script Sync](https://create.roblox.com/docs/scripting/sync).

Автосохранение Team Create обновляет рабочий Place. **Publish** выпускает версию для пользователей с доступом и требует отдельного разрешения. Для контрольной точки используйте **Save to Roblox with Notes**. При расхождении версий сравнивайте изменения с текущим общим Place и переносите по одному; не загружайте старый `.rbxl` поверх правок команды. Перед откатом согласуйте паузу редактирования, чтобы чужое автосохранение не затёрло восстановление.

Новый Experience имеет отдельное хранилище Roblox. В файле сохраняется код `Juggle_v1`, но профили прежней игры не переезжают. Обычный Studio Play с `UseStudioDataStore = false` использует память. Настройки доступа Studio к API, DataStore и перенос данных в этой задаче не меняются. [Область DataStore](https://create.roblox.com/docs/cloud-services/data-stores).
